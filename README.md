# Rule-Based Transaction Fraud Analytics and Monitoring

## Project Overview
This project focuses on identifying potentially fraudulent banking transactions using rule-based anomaly detection techniques.

## Objectives
- Detect suspicious transactions
- Identify unusual transaction patterns
- Monitor fraud risk indicators

## Tools Used
- Python (Pandas)
- SQL
- Excel
- Tableau

## Approach
1. Cleaned and validated transaction data
2. Applied anomaly detection techniques
3. Used Z-Score and IQR methods
4. Identified suspicious transaction behavior
5. Created dashboards for fraud monitoring

## Key Insights
- High-value transactions were flagged
- Unusual transaction spikes were detected
- Location and device inconsistencies were identified
